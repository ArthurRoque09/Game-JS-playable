# Linha Quente Em Miami
Este é um jogo de navegador similar as mecânicas do jogo Hotline Miami, desenvolvido para um projeto de aula.
Temos os comandos básicos como andar: W A S D, atirar: BOTÃO ESQUERDO DO MOUSE, pegar arma do chão: E, atacar com o facão: ESPAÇO.
No jogo temos um tutorial ensinando as mecânicas básicas como andar, atacar, assasinato furtivo, atirar e trocar de armas.
O principal objetivo desta demo é fugir do terceiro andar do prédio, a ideia era ter mais andares e mapas, porém não concluimos a tempo.
